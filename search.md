
# Поиск по фильмам

## Обзор

Система поиска использует гибридный подход, комбинируя семантический поиск на основе RAG (Retrieval-Augmented Generation) с классическим текстовым поиском BM25 для максимальной точности результатов.

## Архитектура

### 1. Клиентская часть (`client/src/pages/search.tsx`)

**Основные компоненты:**
- `SearchBar` - строка поиска с возможностью фильтрации
- `MovieGrid` - отображение результатов в виде сетки
- `AIExplanation` - AI-генерируемое резюме по результатам поиска

**Процесс поиска:**
1. Пользователь вводит запрос в строку поиска
2. При отправке вызывается `handleSearch()`, который:
   - Обновляет URL с параметром `?q=запрос`
   - Отправляет POST-запрос на `/api/search`
3. Результаты отображаются с AI-объяснениями для топ-3 фильмов

### 2. Серверная часть (`server/routes.ts`)

**Эндпоинт:** `POST /api/search`

**Алгоритм работы:**

```
1. Получение запроса пользователя
2. Загрузка всех фильмов из базы данных (до 100)
3. ПОПЫТКА: Гибридный RAG-поиск
   ├─ Проверка инициализации RAG-сервиса
   ├─ Семантический поиск через embeddings
   └─ Комбинирование с BM25 (60% semantic + 40% BM25)
4. FALLBACK: Текстовый поиск
   ├─ Разбиение запроса на слова
   ├─ Поиск совпадений в полях:
   │  ├─ Название (вес: 50)
   │  ├─ Жанры (вес: 20)
   │  └─ Общий текст (вес: 10)
   └─ Сортировка по релевантности
5. Генерация AI-резюме через YandexGPT
6. Добавление AI-объяснений для топ-3 фильмов
7. Возврат результатов с метаданными
```

### 3. RAG-сервис (`server/rag.ts`)

**Модель эмбеддингов:** `Xenova/multilingual-e5-small` (384-мерные векторы)

**Индексация фильмов:**
```typescript
createDocumentText(movie) {
  // Создает текстовое представление фильма:
  "Название (English Title). Год: YYYY. Жанры: жанр1, жанр2. 
   Режиссёр: имя. Актёры: актер1, актер2... Описание фильма."
}
```

**Гибридный поиск:**

1. **Семантический поиск** (`semanticSearch`)
   - Преобразует запрос в embedding-вектор
   - Вычисляет косинусное сходство с векторами фильмов
   - Возвращает топ-результаты по семантической близости

2. **BM25 поиск** (`calculateBM25Scores`)
   - Статистический алгоритм ранжирования
   - Параметры: k1=1.5, b=0.75
   - Учитывает частоту термов и длину документа
   - Нормализует оценки от 0 до 1

3. **Комбинирование** (`hybridSearch`)
   ```
   combinedScore = 0.6 × semanticScore + 0.4 × bm25Score
   ```

**Токенизация:**
- Приведение к нижнему регистру
- Удаление специальных символов
- Фильтрация слов короче 3 символов
- Поддержка кириллицы и латиницы

### 4. YandexGPT интеграция (`server/yandexgpt.ts`)

**Генерация резюме поиска:**
```typescript
generateSearchSummary(query, movieTitles) {
  systemPrompt: "Ты — кинокритик-эксперт"
  userPrompt: "Объясни, как найденные фильмы соответствуют запросу"
  → Возвращает 2-3 предложения
}
```

**Генерация объяснений:**
```typescript
generateExplanation(title, synopsis, userContext) {
  Контекст: "Запрос пользователя: {query}"
  → Объясняет, почему фильм подходит под запрос
}
```

## Примеры работы

### Пример 1: Успешный RAG-поиск
```
Запрос: "Комедия про офис"
Метод: hybrid (RAG)
Результат: 15 фильмов
- Семантически близкие к "офис + комедия"
- Учет жанра через BM25
- AI-резюме объясняет соответствие
```

### Пример 2: Fallback на текстовый поиск
```
Запрос: "Матрица"
Метод: fallback (RAG не инициализирован)
Результат: Точное совпадение по названию
- Высокий балл за совпадение в title (50 баллов)
- Фильтрация по score > 0
```

## Оптимизация

1. **Кэширование**: Embeddings вычисляются один раз при индексации
2. **Ленивая инициализация**: RAG загружается в фоне, не блокируя старт
3. **Инкрементальная индексация**: Добавляются только новые фильмы
4. **Батчинг**: Индексация идет пакетами по 5 фильмов с логированием

## Возвращаемые данные

```typescript
{
  movies: MovieWithRating[],     // Фильмы с рейтингами пользователя
  summary: string,               // AI-резюме результатов
  query: string,                 // Исходный запрос
  searchMethod: "hybrid" | "fallback"  // Использованный метод
}
```

## Обработка ошибок

1. **RAG недоступен** → Автоматический fallback на текстовый поиск
2. **YandexGPT недоступен** → Результаты без AI-резюме
3. **Пустой запрос** → 400 Bad Request
4. **Общие ошибки** → 500 с логированием в консоль

## Производительность

- **Гибридный поиск**: ~5 секунд (включая AI-генерацию)
- **Текстовый поиск**: <100мс
- **Индексация**: ~200мс на фильм
- **Размер модели**: ~25MB (quantized)
