## RAG Pipeline (Retrieval-Augmented Generation)

```
┌─────────────────────────────────────────────────────────────────────────────────────────────┐
│                         RAG + LLM RERANKING PIPELINE                                          │
│                              (searchMode: "semantic")                                         │

│   ┌───────────────────────────────────────────────────────────────────────────────────────┐  │
│   │                              USER INPUT                                                │  │

│   │                                                                                        │  │
│   │  ┌─────────────────────────────────────────────────────────────────────────────────┐  │  │
│   │  │ XenovaLlamaIndexEmbedding (server/ai/xenova-embeddings.ts)                      │  │  │

│   └───────────────────────────────────────────────────────────────────┬───────────────────┘  │
│                                                                       │                      │
│                                                                       ▼                      │
│   ┌───────────────────────────────────────────────────────────────────────────────────────┐  │
│   │  STAGE 2: VECTOR SEARCH (QDRANT)                                 ~500ms               │  │

│   │                                                                                        │  │
│   │  ┌─────────────────────────────────────────────────────────────────────────────────┐  │  │

│   │  │                                                                                  │  │  │
│   │  │ Query: vector similarity search, limit=10                                        │  │  │

│   │  ┌─────────────────────────────────────────────────────────────────────────────────┐  │  │

│   │  │                                                                                  │  │  │
│   │  │ Model: yandexgpt-lite                                                            │  │  │
```
